# 台美股實務首版的前後測紀錄

比較對象：Skill 1.37.15 與 1.37.16 的首次候選快照。兩組各一名原生 `gpt-6.1-terra / high` 評測執行者，使用同一份十題、同一組事先固定的四十個判斷點。評測者只取得各自的 skill 快照及題目，沒有取得標準答案、評分器或另一組輸出。

這是一輪配對的結構化決策回歸冒煙測試，沒有執行券商操作，也不是獨立發布審查。紀錄日期為 2026-11-13（Asia/Taipei）。

## 結果與語意核對

| 判讀方式 | 1.37.15 | 1.37.16 首次候選 | 結論 |

| 核對理由與實際工程決策 | 40/40，10/10 題 | 40/40，10/10 題 | 本輪沒有量到工程正確率提升，也未看到這組題目的決策退步 |

舊版將第一筆狀態寫為「已提交，發布快照失敗」、第二筆寫為「尚未開始，未執行」；其理由明確保留已提交事實、禁止第一筆自動重送，並正確區分第二筆未執行。新版使用 `unknown / not_executed`。將兩者的用字差異當成能力差距，會誇大改善，因此保留原始機器分數，另列語意裁定。

原始結果與判讀依據：[更新前回答](results/before.json)、[更新後回答](results/after.json)、[比較資料](results/comparison.json)。題組及評分程式的 SHA-256 保存在比較資料中；不因看到答案而改題或更換判準。

兩組快照逐檔身分、輸入範圍與最終版差異見 [skill 快照清單](results/skill-snapshots.json)。受測快照都排除 `evals/`；題目另外提供，執行者沒有取得評分器或已發布答案。未來使用本 repo 評測時，也須排除該目錄。雜湊用於識別受測內容，不表示本 repo 已附上所有舊候選的完整副本。

公開快照清單已省略部分來源中繼資料，其餘歷史雜湊與分數保留原值，沒有改算為目前檔案的身分。`1.37.17` 的來源說明調整未重跑這輪 AI 前後測；本頁結果仍只對應上述受測快照。

## 實際觀察到的使用方式

- 新版在延遲識別、撤單晚到成交及 reference 缺漏題，分別選用了對應案例；命令效果題選用了狀態／模組參考。
- 策略保留及小腳本題選用了工程夥伴指引，回答保留當下需求，小型查詢不要求新增工作台或完整狀態盤點。
- 舊版也能從既有 OCO、診斷與 UX 參考做出正確決策，顯示基線已具備不少相關知識。

以上只證明這次提供 skill 的評測中出現該選讀與回答，不能由此聲稱新聊天的自動選用、持續的主動建議或開發速度已被驗證。檔案引用數量也不代表完整工具追蹤或 token 成本。

## 可執行案例的分開驗證

首次候選執行 `python -B -X utf8 -m unittest discover -s examples -p test_practical_cases.py -v`：13 項通過。三個 CLI 示範分別得到單次 create／去重入帳、終態後按 1,500 股出場一次，以及 reference 缺漏仍向讀模型提供 1,000 股部位且無出場計畫。

這些是新寫教學模型的正規化事件與本機 SQLite 證據，沒有執行原工作台歷史版本，也沒有重驗真實 SDK payload 或正式交易。

## 指定模型建議後的修正與證據

另完成使用者指定的一輪 `Claude CLI / claude-fable-5-2 / max` 唯讀建議。只提供整理後的 skill 與評估材料，工具及子代理停用，沒有傳送原始 sessions 或私人交易資料。這輪沒有再次執行原生前後測；本頁的 40/40 比較只對應首次候選。

依建議修正：出場前預留量／授權／行情改為必填，全成交進場不再記撤單；補空識別、未觸發、剛好足量、零部位與可賣量不足等反例；移除把固定 UI／效果旗標當成測試結果的表述；釐清呼叫端未明與帳本事實、guard 變更的既有授權，以及前端歷史摘要與新增建議。

最終教學程式以相同命令完成 **19 項通過**。另外在記憶體內逐一重建七個錯誤變體：空識別誤配、未觸發即出場、剛好足量被擋、略過可賣量、零部位產生計畫、全成交仍撤單、缺少參數卻預設放行；每個變體都被指定測試以 assertion failure 攔下，沒有把匯入錯誤算成成功攔截。

也直接載入留存的修正前教學模型，確認全成交仍記一次撤單，以及省略授權／行情參數仍回傳出場量的現象。這項對照只涉及本次教學程式，非原交易應用。來源／測試 SHA-256、錯誤變體與指定測試名稱見 [模型回歸結果](results/model-regressions.json)。

這批聚焦證據支持教學程式的修正；沒有量測最終文字版本的 AI 決策提升，也沒有第二輪外部複查。

## 有效性結論與下一次適合的測量

首版完成可讀案例、模組與狀態對照、可執行反例及協作提示。此次題組沒有證明決策正確率提高；它的自由文字輸出也暴露了名稱比對評分的限制。

下次有實際開發需求時，可用尚未出現在案例中的原始格式、晚到／缺漏事件或既有程式修補，測到可執行結果與後續恢復；另採事先固定的結構化狀態欄位及人工語意判讀，避免只測術語記憶。這是後續評估方向，不是本輪新增的測試或持續執行承諾。
