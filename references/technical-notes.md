# 同業 API 對照與 SuperPy 技術筆記

把同業 API 的功能問題，轉成有文件依據的 SuperPy 使用方式；使用者要求文件時，再整理成可直接閱讀與分享的技術筆記。查證涵蓋的範圍可以比最後的筆記廣，文件內容依使用者指定的讀者與範圍取捨。

## 何時使用

- 使用者貼同業 API 文件，詢問 SuperPy 有沒有同類功能、欄位怎麼對應，或需要組合哪些方法。
- 使用者想釐清 SuperPy 的交易資格、狀態值、旗標、資料類型或行情事件，並整理為說明文件。
- 使用者要求將已查證的結果製作成精簡 HTML／PDF，附 Python 範例與官方功能連結。

只問功能對照時，在對話中回答；只要求 HTML 時，不額外產生 PDF。後續只改文案、連結或排版時，直接修改既有文件並重新匯出受影響的產物，沿用仍有效的查證結果。單一已知 API 問答、一般券商評比、策略獲利分析與無關的介面美化，不需要完整流程。

台股登入、帳號設定、交易回呼與工作階段的流程筆記，使用 [台股流程參考](session.md#tw-workflow)；不需要先做同業對照。保留帳務查詢與交易的分支，以及斷線、登出的發生時機。

## 從功能語意找對應

1. **先定義要判斷的事情。** 確認市場、商品與交易模式，以及使用者要的是商品資格、帳戶權限、查詢結果還是即時事件。依欄位用途找對應，不要求方法集中在同一個 API，也不按同名方法推測。
2. **讀原始文件。** 先讀使用者提供的同業官方網址；官方文字版可用時可優先讀取。再查 SuperPy 對應的公開官方功能頁，必要時確認目前 SDK 的公開介面或可公開查證的 Server 規格。搜尋摘要與既有 Skill 僅作定位，不能取代未讀過的來源。聲稱目前或最新功能時，核對現行官方文件與相關版本。
3. **比對實際契約。** 確認參數、回傳型別、欄位、值域、單位、方向、更新時間，以及空資料或未知值的處理。Bitmask、布林值、字串代碼與多個資料集可能表達相近能力，但只有語意相符的部分才可對照；不要自行重建未獲文件支持的位元。
4. **拆開容易混淆的條件。** 商品當沖資格不等於帳戶開通、可用額度、持股或價格限制。分開處理整張／零股與不同市場。行情的成交資訊也不等於使用者委託的成交回報。
5. **有足夠依據就收斂。** 回答 SuperPy 要呼叫什麼、讀什麼欄位、如何判斷，以及影響判斷的限制。核心來源矛盾或資料不足時，在對話中保留不確定性；不以猜測補齊功能，也不為純文件查詢執行券商登入或交易。

依問題選讀 [委託](orders.md)、[行情](quotes.md)、[歷史資料](data-and-backtest.md)、相關市場參考與 [來源查證](source-verification.md)。不自動展開整套文件或測試。

## 證據與行情判讀

區分官方已描述的契約、SDK 已提供的包裝、Server 規格已有的能力，以及特定版本與條件下實際觀察到的行為。Server 有功能不能直接寫成 SDK 可呼叫；SDK 尚未包裝也不能直接寫成後端沒有。欄位或回呼處理存在，不代表每個帳戶、行情來源與時段都實測收到相同資料。

判斷行情時，同時確認：

- **事件種類：** snapshot、委買賣、累計量與新的成交資訊分別代表什麼；混合回呼不能逐筆視為新成交。
- **試撮標記：** 依該 API 的值域判斷，與登入模擬環境分開。未知值不能默認為實際成交。
- **時間與欄位有效性：** 哪個群組剛更新、其他欄位是否沿用舊值，以及該資料的市場、交易模式與來源時間。

文件查證與離線檢查不需要正式登入。若另有執行需求，沿用既有授權範圍並遵守 [SKILL.md](../SKILL.md) 的登入與交易規則；製作筆記不會擴大授權。

## 技術筆記的預設內容

使用者指定的目錄、格式、語言與內容範圍優先。未指定位置時，可放在目前專案的 `tech-notes/<主題>/`；同一主題沿用既有 HTML 與 PDF。臨時腳本與預覽放在主機政策指定的暫存位置。

預設以繁體中文撰寫精簡、可獨立閱讀的 SuperPy 說明：

- 參考筆記（reference note）採平鋪直述，描述用途、介面、前提、回傳內容與事件語意；避免以「先把……準備好」、「跟著做」等教學語氣包裝。使用者要求教學時，再採教學形式。規則適合對照時用小表格。
- 每個主題附短 Python 範例並做語法上色。保留正確縮排與 API 拼字；需要時處理空回傳、未知旗標與必要錯誤。若沿用既有 `api`，在正文交代已登入並選妥帳戶的前提，不加入帳密、登入或送單程式。
- 在對應功能名稱放可點擊的官方深層連結。主要文件網址也以完整文字呈現，讓 HTML、PDF 與列印版本都能追溯；檢查長網址不被截斷。
- 有 HTML 流程圖時，各節點連至文件內的對應說明，內容頁提供返回流程圖的連結；官方連結仍指向官網原始功能頁。帳務查詢、交易作業與 callback 各自對應實際內容，不全部連到同一段。只有單一短說明時不必新增流程圖。
- 只保留會影響使用的前提、限制與更新語意，融入相關說明。預設不加入同業對照、未對應功能清單、內部筆記、作業紀錄、私有路徑、SDK 雜湊或機器資訊；使用者明確要求時才擴充。

查證時仍要保留缺口。影響結論的重要不確定性應在對話中說明，或將文件範圍限縮到有依據的部分；不能因文件要求精簡，就把尚未確認的行為寫成既定事實。不要把小範例擴建為應用程式或修改 SDK。

## HTML、PDF 與驗證

1. **先完成 HTML。** 使用 UTF-8、適合繁中的字型、內嵌 CSS 與靜態語法上色，避免離線閱讀依賴 CDN。可用既有 Pygments 或 Python `tokenize` 產生高亮；轉義 HTML 特殊字元並保留程式原文。
2. **要求 PDF 才匯出。** 以同一份 HTML 為來源，使用現有瀏覽器／Playwright 等可用工具，等字型載入後保留背景、列印 CSS、合理紙張尺寸與超連結。按當前環境取得工具路徑，不把本機路徑寫入可分享的技能。需要 PDF 工具細節時選讀已安裝的 PDF skill，不另設批准流程。
3. **檢查內容。** 將 HTML 中的 Python 範例還原後用 `ast.parse` 檢查語法，並核對官方欄位、狀態值與連結。語法通過只證明程式可解析，不代表 SDK 呼叫或行情已實測。
4. **檢查成品。** 將 PDF 全頁轉為預覽圖並逐頁檢視繁中文字、表格、程式碼、網址、斷頁、裁切與重疊；另確認 PDF 超連結可用且完整網址可讀。有流程圖頁內連結時，實際點擊 HTML 節點與返回連結，並檢查 PDF 的內部連結及目的地是否對應正確內容與頁碼；外部官網連結與頁內目的地分別驗證。檢查 HTML 在一般與窄版寬度的程式碼、表格與網址，不要求固定頁數。
5. **交付。** 將正式 HTML／PDF 留在指定目錄，提供檔案連結，簡短交代實際完成的檢查與影響使用的缺口。不要把暫存腳本、預覽或研究紀錄列為主要交付。

一般採直接製作與一次檢查。若排版需要反覆修正，預設最多 **2 次完整匯出**：初稿一次、修正一次；通過即停止，仍有問題則保留可用來源並說明缺口，不無限重跑。使用者另訂預算時依其指示。文件或連結修改不要求重跑無關 SDK／券商測試。

## 已有案例：現股當沖與試撮行情

以下是台灣證券官方文件中的定位例子，不能外推成其他市場或版本的保證。實際引用時仍核對相關來源。

| 要判斷的事情 | SuperPy 入口與讀法 |
| --- | --- |
| 單一股票的現股當沖資格 | [`api.Order.TSECreditInfo(...)`](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/orderTSECreditInfo) 的 `DTCode`：`N` 不可現股當沖、`Y` 僅可先買後賣、`X` 可先買後賣與先賣後買。`MarkT` 是資券當沖欄位，不能當成現股當沖資格。 |
| 批次查詢與當日限制 | [`api.Data.get("上市櫃/ETF清單(含當沖限制)")`](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/getData)：讀取「可先買後賣當沖標的」、「可先賣後買當沖標的」、「當日禁止當沖標的」與「日期」，合併資格、當日禁止與資料日期判斷。 |
| 加值行情是否為試撮 | [Tick](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/quoteSubscribeTick)、[BidAsk](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/quoteSubscribeBidAsk)、[All](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/quoteSubscribeAll) 的 `simtrade`：`0` 非試撮、`1` 試撮。BidAsk 是委買賣更新，All 混合事件不能逐筆當成新成交。 |
| 原始行情的新成交資訊與試撮 | [`SWQuote`](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/swQuoteSubscribe) 的 `SWMarketData` 先看 `data_type == 2`（MatchInfo），再看 `simtrade`。其他資料類型可能保留前次成交欄位，不以價格仍有值判斷新成交。 |

回呼註冊參見 [Quote set_callback](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/quoteSetCB) 與 [SWQuote set_callback](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/swQuoteSetCB)。`simtrade` 是試撮標記；登入的 `simulation` 是另一個設定。

## 可直接使用的提問

功能查證：

```text
請使用 $kgi-superpy-tw，讀取這個同業官方 API 網址，
確認 SuperPy 如何判斷相同能力；若分散在不同方法或欄位，請整理使用方式。
依實際語意對照，附 SuperPy 官方功能連結。這次只回答，不產生文件。
```

技術筆記：

```text
請使用 $kgi-superpy-tw，將已查證的功能整理成精簡繁中 SuperPy 技術筆記。
只寫 SuperPy 使用方式，不加入同業對照、未對應功能或內部筆記。
附簡易 Python 範例、語法上色與官方功能完整網址，先做 HTML 再轉 PDF。
產物放在我指定的目錄，沿用既有同主題文件，檢查 PDF 每頁與連結後交付。
```
